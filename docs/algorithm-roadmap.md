# 算法实现路线

## 1. 研究问题

目标是在普通 RGB 成像条件下检测锂电池极片或电芯壳体上的划痕、针孔、凹坑、污渍、异物和裂纹等微小表面缺陷。

主要困难包括：

- 缺陷在整幅图像中占比很小，缩放后可能只剩数个像素；
- 缺陷对比度低，容易与金属反光和表面纹理混淆；
- 连续下采样会削弱浅层边缘和纹理信息；
- 微小边界框对少量像素偏移非常敏感；
- 高分辨率输入和检测分支会明显增加计算量。

## 2. 总体流程

```text
采集与标注
    ↓
数据审计和分组划分
    ↓
YOLO12n 强基线
    ↓
错误分析与尺寸分析
    ↓
P2 高分辨率检测分支
    ↓
轻量多尺度特征融合
    ↓
IoU / NWD 定位损失实验
    ↓
组合消融、鲁棒性与部署评估
```

每个阶段都必须先提出假设，再通过单变量实验验证。只有单模块能够稳定改善微小目标 Recall 或 mAP50-95，才进入组合模型。

## 3. 阶段一：数据审计

### 3.1 数据划分

不能简单按图片随机划分。如果图片来自连续视频、同一块极片或同一只电池，应按电池编号、生产批次、采集序列或日期分组，再划分为训练集、验证集和测试集。

推荐比例为 70% / 15% / 15%。测试集在模型设计阶段保持冻结。

### 3.2 微小目标统计

设原图尺寸为 `W × H`，训练输入边长为 `S`，采用等比例缩放时：

```text
scale = S / max(W, H)
resized_width = box_width × scale
resized_height = box_height × scale
```

重点统计缩放后短边小于 4、8、16 和 32 像素的目标数量。如果大量缺陷在 640 输入下小于 4～6 像素，应优先提高输入尺寸或切片，而不是直接修改网络。

### 3.3 困难负样本

训练数据应包含适量无缺陷图像，以及反光、油污、边缘、焊点和规则纹理等容易误检的背景。背景图建议占总图像的 5%～10%，最终比例由验证集误检情况决定。

## 4. 阶段二：建立强基线

基准模型使用 COCO 预训练的 YOLO12n。先比较三种输入策略：

1. 640 整图；
2. 1024 或 1280 整图；
3. 640 或 1024 重叠切片，建议初始重叠率为 20%。

选择基线时不能只看总体 mAP，应同时考察微小目标 Recall、各类别 AP、显存占用和端到端推理速度。

训练阶段保存以下信息：

- Git 提交编号；
- 数据集版本与划分文件；
- 随机种子；
- 完整训练参数；
- GPU、CUDA、PyTorch 和 Ultralytics 版本；
- 最佳轮次和停止原因。

## 5. 阶段三：P2 检测头

标准 YOLO12 使用 P3/8、P4/16、P5/32 三个输出尺度。P2 改进增加 P2/4 输出，使检测头能够直接使用更高分辨率的浅层特征。

实现原则：

- 从骨干网络 P2 阶段提取特征；
- 将 P3 特征上采样后与 P2 特征拼接；
- 使用轻量 C3k2 模块整合 P2 特征；
- 检测层改为 P2、P3、P4、P5 四尺度输出；
- 保留原有自顶向下和自底向上融合路径；
- 单独统计新增参数、FLOPs、显存和延迟。

本仓库的 `configs/models/yolo12n-p2.yaml` 是第一版 P2 配置。其目标是验证高分辨率检测分支是否有效，不代表最终最优结构。

## 6. 阶段四：多尺度融合

只有 P2 实验有效时才继续优化融合结构。候选方案应控制在一种，优先考虑轻量加权双向融合，不同时引入多个注意力模块。

YOLO12 本身已经采用注意力中心设计。额外注意力只有在可视化和消融结果显示其能够抑制反光或复杂纹理时才保留。

可重点分析：

- P2 特征是否包含有效缺陷响应；
- 浅层高频信息是否引入更多背景误检；
- P2 与 P3 的通道数是否存在冗余；
- 加权融合是否优于直接拼接；
- 提升是否主要来自计算量增加。

## 7. 阶段五：定位损失

先比较原始 IoU 类损失，再比较 SIoU、WIoU 或 NWD。NWD 将边界框视作二维高斯分布，可减弱微小框对少量位置偏移的过度敏感。

第一轮 NWD 实验只修改回归损失：

```text
L_box = alpha × L_IoU + (1 - alpha) × (1 - NWD)
```

建议测试 `alpha = 0.25、0.50、0.75`。不要同时修改标签分配和 NMS，否则无法确定收益来自哪个环节。

NWD 最初主要在锚框检测器上验证。将其用于现代无锚框 YOLO12 属于适配实验，必须通过消融数据验证，不能预设一定有效。

## 8. 评价指标

准确率指标：

- Precision；
- Recall；
- mAP50；
- mAP50-95；
- 各类别 AP 和 Recall；
- 按缩放后像素尺寸划分的 Recall 和 AP。

工程指标：

- 参数量；
- FLOPs；
- 峰值显存；
- batch=1 的预处理、模型推理和 NMS 延迟；
- 同一硬件上的端到端 FPS。

测试置信度阈值应在验证集上确定。正式测试时固定模型、输入方式、阈值和 NMS 参数。

## 9. 推荐里程碑

1. 完成数据集 v1、标注规范和重复图片检查；
2. 完成 B0、B1、B2 三个输入基线；
3. 形成误检、漏检和目标尺寸分析报告；
4. 完成 P2 单模块实验；
5. 完成融合和定位损失单模块实验；
6. 组合有效模块并完成三随机种子复验；
7. 完成鲁棒性、速度和部署可行性测试。
