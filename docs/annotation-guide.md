# 数据采集与标注规范

## 1. 类别定义

当前采用资料末尾缺陷汇总表中的 19 类 RGB 缺陷。表中第 16 项“光伏电池组件封装异常”按项目决定排除；光伏电池片的裂纹、划痕、断栅和破损仍保留。X-ray 和 3D 模态不纳入本项目。映射细节见 [类别映射表](../configs/data/class-mapping-template.csv)。

| ID | 类别 | 初步定义 |
|---:|---|---|
| 0 | 极片表面裂纹 | 裂纹区域 |
| 1 | 极片涂层剥离 | 剥离区域 |
| 2 | 极片针孔 | 针孔区域 |
| 3 | 极片褶皱 | 褶皱区域 |
| 4 | 铝塑膜破损 | 破损区域 |
| 5 | 铝塑膜针孔 | 孔洞区域 |
| 6 | 铝塑膜鼓胀 | 鼓包区域 |
| 7 | 铝塑膜划伤 | 划痕区域 |
| 8 | 极耳裂纹 | 裂纹区域 |
| 9 | 极耳针孔 | 针孔区域 |
| 10 | 极耳边缘缺损 | 缺损区域 |
| 11 | 光伏电池片裂纹 | 裂纹响应区域 |
| 12 | 光伏电池片划痕 | 划痕响应区域 |

若两类在 RGB 图像中无法稳定区分，应在大规模标注前合并，避免人为制造标签噪声。

## 2. 采集要求

- 保存原始分辨率图像，不提前压缩到训练尺寸；
- 记录电池编号、批次、相机、镜头、曝光、光源、距离和日期；
- 覆盖正常照明变化、轻微失焦、表面反光和不同位置；
- 保留正常样本和困难背景，不能只拍摄明显缺陷；
- 连续采集数据必须保留序列或工件编号，供分组划分使用；
- 如调整相机或照明，应记录为新的采集域。

## 3. 边界框规则

- 边界框尽量紧贴可见缺陷，不包含无关背景；
- 同一缺陷的离散但连续部分使用一个框，互不相连的缺陷分别标注；
- 极细划痕应覆盖完整可辨识长度，框宽包含可见边缘；
- 被截断但仍可判断类别的缺陷需要标注；
- 无法判断类别的疑似区域先进入复核列表，不强制归类；
- 所有可见目标都要标注，禁止只标部分实例；
- 团队成员定期交叉复核同一批样本，统一尺度和类别判断。

## 4. YOLO 标签格式

每张图片对应同名 `.txt` 文件，每个目标一行：

```text
class_id x_center y_center width height
```

四个坐标均相对于原图宽高归一化到 `[0, 1]`。类别编号必须从 0 开始且与最终确认的类别映射及 `configs/data/battery.yaml` 完全一致。

## 5. 数据划分

推荐比例为训练集 70%、验证集 15%、测试集 15%。划分单位优先级如下：

1. 电池或极片编号；
2. 生产批次；
3. 连续采集序列；
4. 采集日期或设备配置。

不能让同一对象的相邻帧进入不同集合。各集合应尽量保持类别分布接近，但不能为了平衡而破坏分组边界。

## 6. 质量检查清单

- 是否存在图片没有检查或漏标；
- 是否存在类别编号越界；
- 是否存在坐标小于 0 或大于 1；
- 是否存在宽高为 0 的框；
- 是否存在明显过松或截断缺陷的框；
- 是否存在训练、验证和测试集重复图片；
- 每类是否在验证集和测试集中都有足够实例；
- 无缺陷图和困难负样本比例是否合理；
- 不同标注人员之间是否存在系统性差异。

在每次数据修订后更新数据版本，例如 `battery-v1.0`、`battery-v1.1`，并保存划分清单和修改说明。
