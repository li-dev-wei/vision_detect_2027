# 对比与消融实验计划

## 1. 实验原则

- 除被研究变量外，其他训练条件保持一致；
- 所有实验使用同一数据版本和划分；
- 筛选阶段使用固定随机种子 42；
- 基线和最终模型使用至少 3 个随机种子复验；
- 结构、损失权重和阈值只能根据验证集选择；
- 测试集仅用于最终报告。

## 2. 输入基线

| 编号 | 模型 | 输入 | 目的 |
|---|---|---|---|
| B0 | YOLO12n | 640 整图 | 标准基线 |
| B1 | YOLO12n | 1024/1280 整图 | 验证输入分辨率影响 |
| B2 | YOLO12n | 重叠切片 | 验证缩放信息丢失问题 |
| B3 | YOLO12s | 最佳输入策略 | 验证模型容量影响 |

整图和切片实验应使用相同原始数据划分。切片的窗口、重叠率、边缘框处理和结果合并方式必须记录。

## 4. 损失函数实验

第一轮只修改边界框回归损失，保持标签分配和 NMS 不变：

| 编号 | 回归损失 | 组合权重 |
|---|---|---|
| L0 | 原始 YOLO12 损失 | 默认 |
| L1 | SIoU 或 WIoU | 单独使用 |
| L2 | IoU + NWD | alpha=0.75 |
| L3 | IoU + NWD | alpha=0.50 |
| L4 | IoU + NWD | alpha=0.25 |

只有回归损失实验显示明确收益后，才考虑将 NWD 用于正样本分配或 NMS，并作为新的独立实验组。

## 6. 错误分析

每个关键实验至少整理以下案例：

- 基线漏检但改进模型检出的微小缺陷；
- 两个模型都漏检的极低对比度缺陷；
- 反光、纹理、边缘造成的误检；
- 类别混淆；
- 边界框定位明显偏移；
- P2 引入的新误检；
- 切片边缘造成的重复框或截断框。

错误分析应同时报告改善和退化案例，避免只展示成功样本。

## 7. 最终复验

最终基线和改进模型建议使用随机种子 42、3407、2027 复验，报告均值和标准差。速度测试在同一台设备上进行，固定输入尺寸、batch=1、精度模式和预热次数，并区分纯模型推理与端到端延迟。
